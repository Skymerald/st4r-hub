Coding

1. HTML

Hero Section

Whooo, now that I explain that, we can go right into coding, first I will make the hero section, pretty simple, I have this code : 


            <main class="hero-section"> <!-- The section element let you define different part of HTML -->
                <h1 class="main-title">Elevate your toilet experience.</h1> <!-- This is the title -->
                <h2 class="secondary-title">
                    ToiletHero is one of the best company in the industry. <br />
                    We introduce our latest technology and design for an always better experience, comfort and efficiency.
                </h2> <!-- And this is the subtitle -->
                <button class="button">See our products</button> <!-- Finally a button -->
            </main>

If you wonder why I use main, it is because I want this to be accounted as the main part of the website, so the search engine use it for affining the search results. For the rest we have the title, the subtitle and a call to action, here to see the products. We'll tackle the CSS later.

Header

2. CSS

Yes it is pretty ugly, so now let’s add CSS ! We’ll start by doing this so we’ll have everything needed for the next sections.

Root and body element

Before everything we need to setup some basics, the body styling and the colors variables : 


            :root{
                font-family: 'Ubuntu'; /*The font variable*/

                --main-color : #144AE1;
                --font-color : #ffffff;

                /*And the colors variables*/
            }
            body{
                width : 98vw;
                margin-right: 0;

                /*Make the page large enough but without a vertical scroll bar*/
            }

The :root element is one element that is going to be applied for every element on the page and this is typically where we declare variables.

Variables in CSS ?!

Yes variables in CSS. They can be declared like this : 


            --color : #000; /*A color*/
            --margin : 95px; /*A value, in every unit available*/
            --font : ‘Roboto’;/*A font*/
            /*It can be used for every values possible*/

And it can be used like this : 


            body{
                Background-color : var(--color);
            }

And then the body element is the full page, so every element are going to be affected by the styling applied in the body element, but it can be overridden by any other styling. Here I just make the body element the size of the viewport (the place where is rendered the website).

Header

Now let’s make the header. We want the logo to the right, the links in the middle and finally, the menu button on the left, it is a good, simple and well used style so it is perfect.
For this we will need this CSS : 


            .navbar{
                display : grid; /*Set up a grid container, with 2 axis support instead of 1 for flexbox*/
                grid-template-columns: 1fr auto 1fr;
                align-items: center;
            }

Here we put the navbar into the grid type of container with a separation of 1 fraction (arbitrary unit to represent a fraction of the container), auto (to make it as big as possible), and 1fr again.
But for now it is not scrolling with us, the first thing coming in your mind might be to use : 

position : fixed;

But in fact we’ll use :

position : sticky;

Like that the navbar won’t be always on top of element, on the very top of the page, it will be considered like a normal element, so it get it own space, and then when scrolling and hitting the top of the page, it will become fixed, we can see it like the navigation of Wikipedia.

Again, sorry for the white background.
Now for the logo, the links and the menu button we’ll use this : 


            .logo{
                width : 12vw; /*Give its size*/
            }
            .navlinks{
                display: flex;
                justify-self: center; /* Put the links in the center */
            }
            .menu-button{
                justify-self: end;

                font-size: 1.5rem;

                background: none;
                border: none;

                border-radius: 10px;

                transition: all 0.2s;
            }
            .menu-button:hover{
                color: var(--main-color);
            }

It is pretty simple, we set the size of the logo, the place of the links, and for the button the only thing we do is make it prettier with the smooth color transition when hovered, thanks to the transition propriety.

Hero Section

After this we can now make the Hero section, what we want is a main title, a subtitle and a button, all above a background image.
To do so, we can use this CSS : 


            .hero-section{
                display: flex;
                flex-direction: column;

                text-align: center;
                justify-content: center;
                align-items: center;

                /* Put the item in the center*/

                height : 60vh; /* Give a size to the container */

                background-image: url(img/hero_background.png);
                background-repeat: no-repeat;
                background-size: cover;

                /* Add a background image and make it adapt with the screen size */
            }
            .main-title{
                font-size: 3rem;
            }

As we can see, it only put the item in the center, set the height of the section, and put the background image. If you are wondering about the button, I will not cover it.

Technology Section

Now I will pass on the story section, because it is something that we already covered and we’ll go directly to the technology section.
With it, we will see is the grid structure, otherwise we already seen everything 


            .cards-container{
                display: grid;
                grid-template-columns: 1fr 1fr;

                gap: 0.5rem;
            }
            .card{
                display: grid;
                grid-template-columns: 5vw 1fr;
                grid-template-rows: 0.5fr 1fr;

                align-items: center;

                grid-template-areas: 
                "icon title"
                "icon text";
            }
            .card > .minor-title{
                margin-bottom: 0.5rem;
            }

So here what is happening, is that I use 2 grid inside each other. The first one is the one for making the card on 2 columns. On the other hand the second one is more interesting due to the layout.
I first declare 2 columns and 2 rows, with a size for each, and then use the grid-template-areas, to set what content is going to be where. You may have seen the style=”grid-area: something;” in the HTML earlier, well it is to give a name to the element to declare what rows and what columns they will occupy in the grid.
Lastly the most interesting thing is the .card > .minor-title, this is only a selector, to tell the browser, that this style only applies to the .minor-title that are inside a .card.

Products Section

Now we will tackle the most interesting part, the products section, I will pass onto the HTML, that only declares the products with an image, a name, a description and some characteristics. And I will also pass on the CSS, that only style the image, name, etc … What is interesting is this : 


            .products-container{
                display: grid;

                grid-template-columns: 5vw auto 5vw;
                grid-template-rows: 1fr;
                grid-template-areas: 
                "origin streamline nexus";

            }

To place the 3 elements, while ensuring the central one takes the most place. I don’t show the CSS to make the elements a certain width, to get the text to go out of the page.

3. JavaScript

Now, the most interesting part, javascript ! Here it is : 


            const leftBtn = document.querySelector('#left-button');
            const rightBtn = document.querySelector('#right-button');

            let productsContainer = document.querySelector('.products-container');
            console.log(productsContainer);

            let products = ["origin", "streamline", "nexus"];

            leftBtn.addEventListener('click', function(e){
                products.unshift(products[2]);
                products.pop();

                productsContainer.style.gridTemplateAreas = `"${products[0]} ${products[1]} ${products[2]}"`;
            });
            rightBtn.addEventListener('click', function(e){
                let shift = products.shift();
                products[2] = shift;

                productsContainer.style.gridTemplateAreas = `"${products[0]} ${products[1]} ${products[2]}"`;
            });

We have 20 lines of pretty complicated code, but I will explain.
First, we select the two button of controls (I didn’t mention them earlier, you can make them yourself at this point) and the products container.
After we declare a list of the name of the grid-area for each products. Before looking at the code for the left button let’s see the right button. First we add an eventListener(a function triggered each time an event happens on the element) for the event of a click. Then we use the shift function on the list, it removes the first element of the list, we store it in a variable and add it back to the end of the list.
And after we only modify the grid-template-areas propriety of the products-container elements with our list.
For the left button, it is the same, we only use the unshift function, that only add the element you want at the beginning of the list, here the last element, and then we remove the last element, since it need to be the first. And after we use the same code.
And voilà ! We have a functioning carousel, but if you want smooth transitions, it is more complicated, and I think it can be a great exercise.

4. Final coding

And I will pass on the last two section that are really simple to do, the last code snippet I will give is to make the hover effect on links (<a> elements), with this code : 


            a::after{
                content: "";
                display: flex;
                position: relative;
                height: 0.2rem;
                width: 0;
                background-color: var(--main-color);

                transition: all 0.2s;
            }
            a:hover::after{
                width: 100%;
            }

And the fade effect for the carousel, with this code : 


            .products-container::before {
            content: "";
            position: absolute;
            top: 0; /* position at the top */
            left: 0;
            width: 100%;
            height: 100%; /* adjust how tall the fade is */
            background: linear-gradient(
                90deg,
                rgba(216, 216, 216, 0.404),
                rgba(255, 255, 255, 0), /* strong fade at top */
                rgba(216, 216, 216, 0.404)   /* transparent towards content */
            );
            pointer-events: none; /* so it doesn’t block clicks */
            z-index: 2; /* sits above carousel items */
            }

And be sure to use it on the container.
