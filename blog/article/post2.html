Petite introduction à la création de page web

25/01/2026

22min

Introduction

Bonjour, aujourd'hui je vais vous guider à travers un petit voyage sur comment créer sa propre page web.
Première chose à savoir, chaque page web est constitué de 3 languages :

HTML


Le HTML est ce qui structure la page, tout le contenu d'une page web est contenu dans un fichier HTML.


CSS


Le CSS est le langage qui stylise chaque élement de la page HTML.


JavaScript

Le JavaScript est le seul langage de programmation des pages web. Il permet d'ajouter des fonctionnalités interactives à une page web.

Les base du HTML

Le HTML est un language utilisant des paires de balises, par exemple : 



            <html></html>
            <h1></h1>

toute page possède les même base : 



            <!DOCTYPE html>
            <html>
            <head>
                <meta charset="UTF-8">
                <title>Document</title>
            </head>
            <body>
                
            </body>
            </html>

Ces balises sont importantes : la première permet d'indiquer que le fichier est un fichier html (elle est optionel).
La deuxième définit le début du fichier html, tout page doit finir par la balise fermante html (avec un "/").
Ensuite il y a la balise head permettant de donner des informations sur la page.
Puis une balise permettant d'utiliser les accents dan la page.
La balise title permet de définir un titre pour la page (le nom indiqué sur l'onglet)
Finalement la balise body permet de définir l'espace où se situera le contenu de la page.
⚠️Une page HTML contient un seul body et un seul head⚠️

Première balise pour créer une page

Les premières balise à connaitre sont celle de textes :


Les titres

Les titres sont faciles à mettre en place : les titres se définissent avec une balise commençant par h puis un chiffre de 1 à 6.
Les titres 1 sont les plus important et 6 sont les moins important.
⚠️Rappelez-vous que le HTML permet seulement de définir le contenu, il ne faut pas utiliser un titre pour sa taille mais pour son importance, la taille peut être défini en CSS⚠️

Les paragraphes

Les paragraphes se font avec une balise p.

Les liens

⚠️Les liens nécessitent des options À L'INTERIEUR de la première balise (entre "<" et ">") pour pouvoir fonctionner⚠️ Pour faire un lien il faut utiliser la balise a avec l'option href avec un lien en valeur et le texte à afficher entre les deux balise.
Exemple : 


                <a href="https://google.com">Un lien</a>
Ce code va afficher "Un lien" et va renvoyer vers "google.com" (toujours ajouter "http://" ou "https://" pour que le lien fonctionne).
Vous pouvez aussi ouvrir le lien dans un nouvel onglet en utilisant l'option target avec la valeur _blank : 

                <a href="https://google.com" target="_blank">Un lien</a>

Maintenant que vous savez utiliser des balises de bases vous voudrez surement ajouter différentes choses à votre page.

Les images

⚠️Les images sont légerement différentes du restes des balises : elles n'ont pas de balise fermantes(la deuxième).⚠️
De plus les images nécessitent deux options tout comme les liens : le premier est src qui permet de donner le chemin de l'image et alt.
⚠️Le chemin doit être relatif à votre fichier HTML ; exemple mon image s'appele chat.png et se trouve dans le dossier image, le chemin sera "image/chat.png", les chemins ne peuvent pas contenir d'espace⚠️
L'option alt est nécessaire pour donner une description de l'image, elle s'affiche quand l'image ne se charge pas, elle est lue par les logiciels pour personne malvoyante, et permet d'afficher une infobulle lorsque la souris passe au dessus.
Exemple : 


                <img src="image/chat.png" alt="une image de chat" />

Les boutons

Les boutons ne sont pas réellement utiles pour une page web basiques, mais c'est intéressant de savoir comment le faire.
La balise pour le bouton est la balise button avec entre les deux balise le texte affiché (comme un lien sans href). Exemple : 


                <button>Un bouton</button>
Ce code va simplement afficher un bouton avec inscrit "Un bouton".

Les conteneurs

Les conteneurs sont très important, ils permettent de contenir d'autres contenus à l'interieur.
Le plus basique est div qui permet de faire un conteneur classique.
⚠️Un conteneur permet de contenir d'autres éléments comme body mais cela n'est pas forcément visible, encore une fois le HTML structure simplement la page⚠️ Les différents conteneurs sont div (le basique), main permettant de mettre le contenu principal, section pour faire des section, nav pour la navigation, et header pour le haut de la page avec le footer pour le bas de page.
Concretement un page peut s'organiser de tel manière : 


                <body>
                    <header>
                        <!-- Élements du haut de page -->
                    </header>
                    <main>
                        <nav>
                            <!-- Élements de la navigation -->
                        </nav>
                        <section>
                            <!-- Première section -->
                        </section>
                        <section>
                            <!-- Deuxième section -->
                        </section>
                    </main>
                    <footer>
                        <!-- Élement du bas de page -->
                    </footer>
                </body>

Les commentaires

Les commentaires ne sont pas nécessaire et ne vont pas être affiché mais sont important pour pouvoir donner des informations à ses collaborateurs ou à son soi du futur.
Pour le faire il faut : 


                <!-- Un commentaire -->


Et voici la fin du HTML

Le CSS

Le CSS permet de styliser une page HTML en appliquant différent style.
Les CSS signifie Cascading Style Sheet et cela est important, puisque cela indique qu'il agit en cascade (j'en dirais plus, plus tard).

Connecter HTML et CSS

Pour ajouter du CSS à une page HTML il faut d'abord créer un fichier CSS, par convention il s'appele "style.css", puis dans le head du HTML il faut ajouter : 


                <link rel="stylesheet" href="style.css">
Et maintenant le CSS sera appliqué au HTML.

Les base

Pour appliquer un style CSS sur des élement HTML il faut pouvoir les sélectionner, il y a différents moyens de le faire :
Dans le CSS sélectionner tout les element d'un balise (tout les <img/> ou tout le <p></p>) simplement en écrivant le nom de la balise
⚠️Sans les "<" ou ">"⚠️ Exemple : 


                /*Code CSS*/
                img{
                    /*Des propiétés*/
                }
Ensuite il est possible d'utiliser l'option class dans le HTML pour donner une classe à l'élement HTML. Class peut être utilisé sur différent élement HTML.
Dans le CSS il faut faire . et le nom de la classe.
Exemple : 

                <!-- HTML -->
                <body>
                    <p class="text">Du texte</p>
                </body>
            

                /* CSS */
                .text{
                    /*Des propiétés*/
                }
Après il y a les id. Il sont pareils aux class
⚠️Mais dans le CSS il faut utiliser "#", de plus il peuvent être appliqué à un seul élement HTML⚠️
Exemple : 

                <!-- HTML -->
                <body>
                    <p id="text">Du texte</p>
                </body>
            

                /* CSS */
                #text{
                    /*Des propiétés*/
                }
Finalement il y a les style directement appliqué aux élements HTML, ce n'est pas recommendé de le faire mais c'est possible.
Exemple : 

                <!-- HTML -->
                <body>
                    <p style="/*Du CSS*/">Du texte</p>
                </body>
Tout les élements de style suive la même application d'abord les élement géneraux sont appliqué puis les classe, ensuite les id et finalement les style dans le HTML, donc 
p>.text>#text>style="/*CSS*/"

Attributs de base

Maintenant que vous savez sélectionner des élements HTML pour les manipuler en CSS, il faut savoir comment les manipuler !


Manipulation de texte

Il y a différents moyens de manipuler du texte, il y a d'abord la couleur
Exemple : 


                .texte{
                    color : red;
                }
Comme vous le voyez tout les attributs CSS sont entre accolades, puis suis le nom de l'attribut, deux-points et sa valeur, toujours succéder d'un point virgule.
Après la couleur il y a les polices : d'abord il y a font-size qui peut prendre différentes valeurs.
Cela permet d'attribuer une taille au texte : la valeur peut être en pixel(px), en rem ou em(des valeurs arbitraires), en vh(view height, de 0 a 100, 100 est la hauteur de la page), ou en vw(comme le vh mais pour la largeur).
Ensuite pour le texte il y a font-family qui permet d'utiliser une autre police, celle de base sont : 'Impact', 'Arial', 'Times New Roman' et 'Helvetica'.
Finalement pour le texte il y a le text-decoration qui permet d'ajouter des élements comme un soulignement. Les valeurs possible sont 'underline', 'overline', 'wavy' et 'dotted'.
⚠️Pour le soulignement il est possible de cumuler différentes valeurs⚠️
Exemple : 

                .texte{
                    color : #000; /*noir, c'est une valeur héxadécimal que vous pouvez obtenir sur un color picker*/
                    font-size : 2rem; /*taille de police*/
                    font-family : 'arial'; /*type de police*/
                    text-decoration : underline wavy; /*souligné et en forme de vague*/
                }

Background

Maintenant que vous savez manipuler du texte ajoutons un arière plan.
Ici nous verrons uniquement deux arrière plan, le fond uni : 


                .texte{
                    background-color : rgb(0,0, 255); /*bleu, c'est une valeur r g b que vous pouvez aussi obtenir sur un color picker*/
                }
Et le fond d'image : 

                .texte{
                    background-image : url('le lien de l'image'); /*le lien est le même que pour une image en HTML*/
                }

Border

La dernière chose que nous verrons ici est la bordure, attribut border qui prend trois valeur : une taille (avec les même unité que la font-size), un type, et une couleur.
⚠️Vous devez toujours suivre ce patterne ou la bordure peut mal s'afficher⚠️
Il y a 4 valeur pour le type de bordure : 'solid', 'dashed', 'dotted' et 'outset'.
Exemple : 


                .text{
                    border : 0.1rem solid purple; /*Une bordure de 0.1rem continue et violette*/
                }
